02 / FAQ

Common questions

Practical answers, without leaving your game behind.

Which files can I import?+

NES: .nes · GB/GBC: .gb, .gbc · NDS: .nds · PSP: .iso, .cso, .pbp. For PSP homebrew, import the complete folder with EBOOT.PBP at its root. This support page does not distribute games or system files.

How do I import games?+

First, save files you have the right to use in the Files app. Tap + in the library, choose a game file, confirm its platform, and import it. NES, GB/GBC, NDS, and PSP ISO/CSO/PBP files are supported. Extract archives first. For PSP homebrew, select the entire folder containing EBOOT.PBP at its root.

Why won't a game run?+

Check that the file matches the platform, is complete, and is not encrypted. Renaming an extension does not convert a format. Some games require separately supplied system files or may be incompatible with the current core.

How do I pause and save?+

Tap Menu in the emulator to open the pause panel. You can resume, save progress, load a save, restart, or exit. Save states depend on core support; a rejected save shows a reason. Loading replaces current unsaved progress.

Can I rename a game without losing its saves?+

Use the rename option in the game details. This changes only the library display name; it does not rename the ROM file or move its associated saves.

Directional buttons, joystick, and sound+

In Menu → Touch settings or Settings → Touch controls, choose directional buttons or a joystick and adjust size and opacity. The joystick center sends no direction; release it to stop. PSP also has a separate analog stick. Toggle sound with the mute button above the game. Settings are saved automatically.

How do I play in landscape?+

Turn off Portrait Orientation Lock in Control Center and rotate your device. NDS uses top/bottom screens in portrait and side-by-side screens in landscape.

How do I change advertising privacy choices?+

Open Settings → Ads and Privacy in the app to reopen available Google privacy options. Apple tracking permission is separate and can be managed in iOS Settings → Privacy & Security → Tracking. Declining tracking does not prevent gameplay; the system may not show a prompt if requests are disabled or a choice already exists.

Can I continue after removing a game?+

Removing a game deletes its managed copy but keeps separate saves in the Saves folder. Data that PSP homebrew writes into its own folder is deleted too. Import the same content again to use matching saves.
